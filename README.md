# Game Platform

One React + Vite app that hosts a small library of offline browser games. Each game is self-contained under `public/games/<id>/` and embedded in an iframe, so games can't interfere with each other.

| Game | Notes |
|---|---|
| Flappy Bird | |
| Comet Critters | |
| Bloom | Draw a garden with your hand; needs a webcam and internet (MediaPipe from a CDN) |

## Run

Requires Node 22+.

```bash
npm install
npm run dev        # http://localhost:5173
```

## Build

```bash
npm run build      # static output in dist/
npm run preview
```

`dist/` and `node_modules/` are not committed and are regenerated by the commands above.

## Add a game

1. Put it in `public/games/<id>/index.html` (use relative URLs for assets).
2. Add an entry to `src/games.js`.

Games that need a backend live in their own repos (`meaning-games`, `living-overworld`).
